# Blinkit-Sales-Dashboard
Interactive Excel dashboard for Blinkit sales analysis featuring KPI tracking, category performance, outlet insights, and sales trends.
This project analyzes Blinkit's sales performance using Microsoft Excel. The dashboard provides insights into sales trends, product categories, outlet performance, customer ratings, and key business metrics.

##Tools Used:
1. Microsoft Excel
2. Pivot Tables
3. Pivot Charts
4. Slicers
5. Conditional Formatting

##Key Metrics
1. Total Sales
2. Average Sales
3. Number of Items Sold
4. Average Rating

## Insights
1. Top-performing product categories
2. Sales distribution by outlet size and location
3. Impact of fat content on sales
4. Year-wise outlet performance trends
